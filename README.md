# dscursor

Creating design systems with Cursor.

## Student Management Portal

Interactive admin portal design for the KBZPay Student Ambassador Program.

**Brand:** `#002c76` · **Typeface:** Poppins

### Preview (recommended)

```bash
# from repo root
python3 -m http.server 5173
```

Then open: [http://localhost:5173/docs/student-management-portal.html](http://localhost:5173/docs/student-management-portal.html)

### Modules

| Side nav | Capabilities |
| --- | --- |
| Student Record | Add / search / filter / export; single entry + Excel import |
| Partner School | College records, status, contacts, logo |
| Event Management | Events, registrations, PDF + cover + meeting link |
| Volunteer Management | Volunteer drives with duration, PDF, cover |
| Job Management | Vacancies by type, JD PDF + cover photo |
| KPI Management | Import KPI (.xlsx) with validation |
| Hall of Fame | Award showcase + manage table |
| Certificate Management | ZIP upload by SA Batch + distribute |

### Cursor Canvas (IDE only)

If you are in **Cursor Desktop**, you can also open the canvas via **Command Palette → “Open Canvas”** and choose `student-management-portal`. Clicking a chat file-path link often shows “page not found” (known Cursor issue) — use Open Canvas instead.
